A Dockerfile at /opt/course/image/api-server.Dockerfile is currently using a full Ubuntu base image with uncessary packages that increase attack surface

Convert the Dockerfile to use a minimal distroless base image by:
- Changing base image to gcr.io/distroless/base
- Removing package managers (apt-get, dpkg) and shell (bash)
- Coping only the necesarry application binary
- Setting the non-root user (nonroot)
- exec form ENTRYPOINT

DO NOT ADD NEW LINES

---

FROM ubuntu:20.04
RUN apt-get update && apt-get install -y curl wget python3 python3-pip
RUN useradd -m appuser
COPY ./app-server /app/server
RUN chmod +x /app/server
USER root
ENTRYPOINT /app/server

-- SECURING THE DOCKERFILE ABOVE!

FROM gcr.io/distroless/base
COPY ./app-server /app/server
USER nonroot:nonroot
ENTRYPOINT ["/app/server"]
